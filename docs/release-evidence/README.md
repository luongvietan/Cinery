# Release Evidence

This directory holds machine-verifiable release evidence.

- `YYYY-MM-DD-mvp-release-candidate.md` — automated gate results and
  production-bundle artifacts (path, size, SHA-256), generated by
  `scripts/verify-mvp-release.ps1`.
- `YYYY-MM-DD-clean-install.md` — the manual clean-install smoke record,
  created from `clean-install-template.md`. This is the only evidence that
  may promote the release status from `MVP RELEASE CANDIDATE` to
  `MVP IMPLEMENTED`.
- `logs/` — raw command logs captured during verification.

Rules:

- Automated evidence never claims `cleanInstallPassed: true`.
- `MVP IMPLEMENTED` may only be recorded after a real clean-install pass
  with tester, OS version, installer hash, and timestamps.
